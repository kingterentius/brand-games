# Brand games

**Goal:** host two short, game-style surveys that help customers and clients put their brand into words.
**Who it's for:** Terence Latimer's clients and prospects, and anyone maintaining this hosting.

- `brand/` — See Your Brand, served at brand.terencelatimer.com
- `voice/` — Tune Your Voice, served at voice.terencelatimer.com
- `flow/` — Map Your Flow, served at flow.terencelatimer.com
- `functions/intake/` — saves each finished card to Odoo CRM

Hosted on Firebase Hosting in the Google Cloud project `tle-operations`. Deploy from Cloud Shell with `firebase deploy --only hosting`.
